## Team working agreement

- Each member works on a separate branch for assigned work.
- Use clear commit messages describing the actual change.
- Open a pull request or review changes before merging to `main`.
- Avoid multiple people editing the same notebook section simultaneously.
- Before merging, run the notebook and check that outputs are reproducible.
- Each member reviews and understands the work of other members.
